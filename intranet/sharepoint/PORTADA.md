# Biblioteca de prompts para Microsoft 365 Copilot

Encuentre prompts profesionales para buscar información, redactar, analizar datos, preparar presentaciones, gestionar reuniones y convertir resultados en planes verificables.

## Empiece en tres pasos

1. Elija una categoría según el resultado que necesita.
2. Sustituya los campos entre corchetes y añada fuentes autorizadas.
3. Revise la respuesta antes de compartirla o ejecutar acciones.

## Explorar categorías

| Categoría | Resultado principal |
|---|---|
| Búsqueda y síntesis | Encontrar y contrastar información |
| Escritura y edición | Crear y mejorar documentos |
| Datos y decisiones | Analizar patrones y escenarios |
| Presentaciones | Construir narrativas visuales |
| Correo y calendario | Reducir carga comunicativa |
| Reuniones | Recuperar decisiones y acciones |
| Conocimiento colaborativo | Organizar notas e ideas |
| Encuestas | Recopilar información útil |
| Gestión documental | Consultar y gobernar contenido |
| Planificación y automatización | Convertir resultados en ejecución |

En SharePoint, convierta esta lista en un elemento web **Vínculos rápidos** y use las URL definidas en [SITE_MAP.md](SITE_MAP.md).

## La fórmula de un buen prompt

**Objetivo + Contexto + Fuente + Expectativas**

> “Resume las decisiones del proyecto para el comité ejecutivo, usando el acta y el hilo de correo. Devuelve una tabla con decisión, responsable, fecha y referencia. Marca cualquier información que falte.”

## Automatice el trabajo recurrente

Use la guía **Tareas programadas en Copilot** para configurar briefs diarios, revisiones semanales, seguimiento de compromisos y vigilancia de proyectos. Las plantillas preparan resultados y borradores, pero mantienen aprobación humana para acciones sensibles.

## Uso responsable

- Utilice únicamente fuentes autorizadas.
- Verifique cifras, citas, fechas y compromisos.
- No use Copilot para inferir desempeño, emociones o rasgos personales.
- Mantenga aprobación humana para decisiones sensibles o acciones automáticas.
