# Análisis de datos y toma de decisiones

[← Escritura y edición](02-escritura-edicion.md) · [Portada](README.md) · [Presentaciones →](04-presentaciones.md)

> **Habilidad:** analizar patrones y explicar resultados.
> **Aplicaciones:** Excel y Analyst.
> **Control:** use tablas limpias, documente unidades y no confunda correlación con causalidad.

| # | Prompt listo para usar | Implementación |
|---|---|---|
| 1 | “Analiza la tabla `[nombre]`. Describe columnas, tipos, unidades, valores faltantes, duplicados y posibles errores. No corrijas datos.” | Revise calidad antes de calcular. |
| 2 | “Analiza `[métrica]` por `[periodo/segmento]`. Identifica tendencia, estacionalidad, cambios y anomalías. Muestra cálculos y propone una visualización.” | Verifique fórmula, escala y periodo. |
| 3 | “Compara `Real` frente a `Presupuesto`. Calcula variación absoluta y porcentual por `[categoría]` y explica los principales impulsores.” | Confirme monedas, signos y valores cero. |
| 4 | “Segmenta `[clientes/productos]` usando `[variables]`. Describe criterio, tamaño y rasgos. Evita etiquetas valorativas y atributos sensibles.” | Valide utilidad operativa. |
| 5 | “Busca valores atípicos en `[métricas]` durante `[periodo]`. Explica el método y distingue error probable, evento excepcional y variación no explicada.” | Investigue antes de excluir datos. |
| 6 | “Construye escenarios conservador, base y expansivo para `[resultado]`. Muestra supuestos, fórmulas y sensibilidad. No presentes proyecciones como garantías.” | Mantenga supuestos en celdas visibles. |
| 7 | “Propón una fórmula para `[resultado]` desde `[columnas]`. Explica cada parte, maneja vacíos y errores, y muestra tres ejemplos.” | Pruebe en una columna temporal. |
| 8 | “Diseña un panel para `[audiencia]` con máximo seis KPI. Define cada indicador, recomienda gráfico y alerta, y justifica exclusiones.” | Valide accesibilidad y carga visual. |
| 9 | “Compara `[cohorte A]` y `[cohorte B]` en `[métricas]`. Reporta diferencias, tamaño de muestra y limitaciones. No atribuyas causalidad.” | Revise sesgo de selección. |
| 10 | “Redacta un memo para `[decisor]` con hallazgos, evidencia, incertidumbre, opciones y preguntas pendientes. Referencia hojas, tablas o celdas.” | Recalcule manualmente cifras críticas. |
