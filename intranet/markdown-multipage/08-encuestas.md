# Encuestas y recopilación de información

[← Conocimiento colaborativo](07-conocimiento-colaborativo.md) · [Portada](README.md) · [Gestión documental →](09-gestion-documental.md)

> **Habilidad:** diseñar formularios neutrales y analizables.
> **Aplicación:** Forms.
> **Control:** defina población, decisión y tratamiento de datos antes de recopilar.

> [!TIP]
> Diseñe primero el plan de análisis. Si una pregunta no contribuye a una decisión, probablemente no necesita recopilarla.

<details open>
<summary><strong>Ver los 10 prompts</strong></summary>

| # | Prompt listo para usar | Implementación |
|---|---|---|
| 1 | “Crea una encuesta de 10 preguntas para medir `[experiencia]` en `[población]`. Combina escalas, opciones y dos preguntas abiertas.” | Revise longitud, anonimato y privacidad. |
| 2 | “Diseña un formulario para identificar necesidades de `[formación/proceso]`. Mide frecuencia, impacto, confianza y prioridad.” | Evite preguntas dobles; haga un piloto. |
| 3 | “Crea una inscripción para `[evento]` con datos mínimos, logística, accesibilidad, consentimiento y confirmación. Señala campos innecesarios.” | Aplique minimización de datos. |
| 4 | “Genera una retrospectiva breve para `[proyecto]`: qué funcionó, qué falló, impacto, aprendizaje y mejora prioritaria.” | Limite a cinco minutos. |
| 5 | “Crea preguntas para medir reacción, aprendizaje, aplicación esperada y apoyo necesario tras `[curso]`.” | Separe satisfacción de aprendizaje. |
| 6 | “Diseña un sondeo sobre `[opciones]` con explicación equilibrada. Recoge preferencia, criterio y confianza. No lo presentes como decisión vinculante.” | Explique cómo se usará. |
| 7 | “Revisa este formulario para detectar sesgo, ambigüedad, preguntas dobles, escalas inconsistentes, datos innecesarios y accesibilidad.” | Revise con privacidad cuando aplique. |
| 8 | “Propón lógica de ramificación. Indica condición, destino y motivo de cada salto. Evita rutas sin salida.” | Pruebe todas las rutas. |
| 9 | “Crea un plan de análisis que relacione cada pregunta con métrica, segmentación, visualización y decisión.” | Defínalo antes de recopilar. |
| 10 | “Resume las respuestas para `[audiencia]`. Separa datos cuantitativos, temas cualitativos y citas anonimizadas. Incluye muestra y limitaciones.” | Proteja identidades y grupos pequeños. |

</details>
