# Gestión documental y conocimiento corporativo

[← Encuestas](08-encuestas.md) · [Portada](README.md) · [Planificación y automatización →](10-planificacion-automatizacion.md)

> **Habilidad:** localizar, revisar y gobernar contenido corporativo.
> **Aplicaciones:** SharePoint, OneDrive y Copilot Chat.
> **Control:** revise permisos, vigencia, propiedad y etiquetas.

| # | Prompt listo para usar | Implementación |
|---|---|---|
| 1 | “Encuentra la política vigente sobre `[tema]`. Prioriza documentos aprobados y recientes. Devuelve título, propietario, fecha, estado, enlace y pasajes.” | Confirme que “vigente” sea explícito. |
| 2 | “Compara `[política A]` y `[política B]` por alcance, obligaciones, excepciones, responsables y fechas. Cita secciones y contradicciones.” | Consulte al propietario documental. |
| 3 | “Crea un inventario de documentos sobre `[tema]`. Agrupa por tipo, propietario, fecha y estado. Señala duplicados y revisiones vencidas.” | No archive automáticamente. |
| 4 | “Propón metadatos para `[biblioteca]`: tipo, área, propietario, vigencia, confidencialidad y tema. Define reglas y valores.” | Valide con arquitectura de información. |
| 5 | “Resume `[documento]` para `[audiencia]` y enlaza cada conclusión a la sección fuente. Incluye versión, fecha y propietario.” | Preserve trazabilidad. |
| 6 | “Identifica contenido potencialmente obsoleto por fecha, enlaces, propietario o conflicto. Propón revisión; no elimines nada.” | Confirme con el propietario. |
| 7 | “Reúne documentos esenciales para incorporar a alguien a `[proyecto]`: propósito, estado, plan, decisiones, riesgos y contactos.” | Revise acceso antes de compartir. |
| 8 | “Responde `[pregunta]` usando solo `[política]`. Cita la sección. Si no responde, dilo e indica a quién consultar.” | No sustituye asesoría profesional. |
| 9 | “Lista evidencia disponible para `[control]`: ubicación, propietario, periodo y brecha. No declares cumplimiento.” | La conclusión corresponde a auditoría. |
| 10 | “Propón un ciclo documental: creación, revisión, aprobación, publicación, actualización y archivo. Define roles y criterios.” | Aprobación de seguridad y cumplimiento. |
