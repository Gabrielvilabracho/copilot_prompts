## Características editoriales

- Tabla de navegación principal.
- Anclas estables para las 10 categorías.
- Navegación anterior, inicio y siguiente.
- Ruta rápida antes del contenido detallado.
- 100 prompts con implementación.
- Gobierno, seguridad, métricas, antipatrones y fuentes.

## Publicación

1. Publique `MICROSOFT_365_COPILOT_PROMPTS.md` como una página única.
2. Verifique que el motor Markdown conserve anclas HTML (`<a id="…"></a>`).
3. Si el intranet elimina HTML, sustituya los enlaces `#categoria-N` por las anclas generadas automáticamente por la plataforma.
4. Añada propietario, fecha de revisión y canal de soporte en los metadatos del intranet.
